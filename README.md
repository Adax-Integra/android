# Adax Integra - Android App

Aplicacion movil de Adax Integra para la plataforma Android. Este repositorio contiene el codigo fuente del cliente movil y la configuracion necesaria para su desarrollo y ejecucion.

## Requisitos Previos

Antes de comenzar con la instalacion y configuracion del proyecto, asegurate de contar con las siguientes herramientas instaladas:

* Git
* Android Studio (se recomienda la version mas reciente)

## Guia de Inicio Rapido

Sigue los pasos a continuacion para clonar el proyecto e inicializar la aplicacion desde Android Studio.

### 1. Clonar el Repositorios

```bash
# Clonar el repositorio de Android
git clone git@github.com:Adax-Integra/android.git
```
### 2. Abrir e Inicializar el Proyecto en Android Studio

1. Abre Android Studio.
2. Selecciona la opción Open (Abrir) y navega hasta el directorio donde clonaste el repositorio android.
3. Espera a que Gradle finalice la sincronización del proyecto y descarga de dependencias.
4. Selecciona un emulador o un dispositivo físico conectado y presiona el botón Run para compilar y ejecutar la aplicación.
